# System Architecture

## Components
- **Frontend**: Next.js UI for user interaction
- **AI Agent**: Python service with OpenAI integration
- **Blockchain**: Solidity smart contracts on Ethereum/Polygon
- **Storage**: IPFS for metadata

## Data Flow
1. User inputs brand details
2. AI recommends domains
3. User selects and mints NFT
4. Ownership recorded on-chain
